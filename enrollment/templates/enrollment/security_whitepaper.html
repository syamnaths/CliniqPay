Enterprise Security, Encryption & DPDP Standards

Architecture Specification v2.4 · 256-bit AES & Multi-Tenant Isolation

enhanced_encryption

1. Cryptographic Data In-Transit and At-Rest

All communication between clinical tablet browsers, cashier desktop desks, and CliniqPay servers is mandated across TLS 1.3 encryption. Passwords and credentials are cryptographically hashed using PBKDF2 with SHA-256 (390,000+ iterations) and salt. Plaintext credentials are never committed, logged, or serialized.

domain

2. Zero Cross-Tenant Leakage Guarantee

CliniqPay enforces tenant isolation at the ORM layer. Every patient record, prescription, bill item, and financial summary is strictly partitioned by hospital tenant context. Staff session privileges are verified server-side, preventing cross-hospital unauthorized data inspection.

key

3. Cryptographic Webhook Authentication (YouPI-PG & WhatsApp)

Inbound webhook transactions from payment engines (including YouPI-PG sovereign UPI relays) require constant-time HMAC-SHA256 signature verification over raw request payload bytes. Unsigned or tampered requests are immediately dropped with HTTP 401 Unauthorized.

devices

4. Patient Counter Tablet Tokenized Security

Patient-facing counter display tablets are protected via cryptographic 64-character entropy display tokens, eliminating authentication credential exposure on public counter touchscreens.

To report a security vulnerability or request an audit verification certificate, please email security@cliniqpay.com.
